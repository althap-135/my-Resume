## ✨ Portfolio Features

### 🎬 Cinematic Intro Animation
- Person (background-removed cutout) **walks from far to front** with realistic scale + bounce
- **"MOHAMED ALTHAP"** assembles from scattered canvas particles behind the figure
- Red fog, floor reflection, decorative text — inspired by a professional poster template
- Auto-transitions to main portfolio after ~5.5 seconds
- **Skip Intro** button available

### 🖱️ Interactive Effects
- **Custom glowing cursor** — red dot + trailing ring
- **3D photo rotation** — profile photo rotates/rolls as you move the cursor
- **Mouse parallax** — Three.js particle background shifts with cursor
- **Tilt cards** — project and about section cards tilt on hover

### 🌌 Three.js Background
- Red/white particle galaxy with 600 floating dots
- Wireframe icosahedron shapes rotating in 3D space
- Camera moves subtly with mouse

### 📐 Hero Layout (3-Column)
| Left Column | Center Column | Right Column |
|---|---|---|
| Tech stack with skill bars | Rolling 3D profile photo | Quick project list |
| Terminal widget | Name + typed role | Live stats (CGPA, Projects, Certs) |

### 📱 Sections
- **Home** — Cinematic hero with 3-column layout
- **About** — Bio, education timeline, badges
- **Skills** — Animated skill bars in 3 categories
- **Projects** — Photo left, project cards right (with tilt)
- **Certifications** — Grid with gold highlight for NASSCOM
- **Contact** — Big bold layout + working mailto form

## 🖨️ How to Download Resume as PDF

1. Open `resume.html` in browser
2. Click **"DOWNLOAD / PRINT PDF"** button (top-right)
3. In the print dialog:
   - Destination → **Save as PDF**
   - Paper size → **A4**
   - Margins → **None**
   - Background graphics → **✅ Enabled**
4. Click **Save**

## 🏃 How to Run Locally

No server needed — just open in browser:

```bash
# Option 1: Double-click index.html in File Explorer

# Option 2: Use VS Code Live Server extension
# Right-click index.html → Open with Live Server

# Option 3: Python simple server
python -m http.server 8000
# Then visit http://localhost:8000
```
